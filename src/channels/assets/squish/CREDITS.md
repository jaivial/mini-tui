# Squishmoji group avatars (server side)

`squish/*.jpg` are square 512×512 JPGs pre-rendered from the same SpaceUI
squishmoji set the web sidebar uses ([`@usespaceui/squishmoji`](https://github.com/usespaceui/squishmoji),
MIT — generated by `scripts/gen-squishmoji.ts` + `scripts/squishmoji-jpg.ts`,
white background because WhatsApp crops group photos circularly and JPG has no
alpha). They replace the Blobmoji set (`assets/emoji/`, now removed).

`avatarFileFor` in `groupAvatar.ts` mirrors `web/src/lib/avatar.ts`: same FACES
list, same hash — a session wears the same face on the web panel and in its
WhatsApp group photo.
