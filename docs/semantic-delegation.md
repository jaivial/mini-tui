# Semantic delegation and visual boards

All web descendants inherit MINI_AGENT_GRAPH_RAG_URL=http://127.0.0.1:9446/. The common Rust launch path retrieves for spawn, dispatch, plans, delegate and handoff, including nested launches. The terminal binary and its environment are unchanged.

The local Python service uses fastembed/ONNX **multilingual-e5-small** (intfloat), 384 dimensions, quantized qint8, two CPU threads, with `query:`/`passage:` prefixes — the multilingual model that replaced v1's all-MiniLM-L6-v2 and its .28 threshold; `docs/rag10-qa.md` carries the QA record of that change. Embeddings and source text are stored on MiniAgent, MiniTask and MiniCard as versioned `MiniChunk` nodes with `HAS_CHUNK` edges in the existing neo4j-rust Bolt graph (900-char windows, 150 overlap; only the current `rag_hash` revision is searchable, old revisions stay for history). Retrieval is exact cosine with lexical reranking over at most 8,000 candidates scoped to the session tree or exact project cwd, with an E5-specific .70 cosine floor, a relative score window (.10 below the ceiling), at most 6 chunks and at most 2 per source, and identical chunk texts dropped. Generic /, /tmp and home directories do not authorize cross-session project retrieval. No remote embedding API.

Retrieved text is historical evidence, never instructions or permission. Each result includes source ID, session and score; MiniRetrieval nodes plus RETRIEVED edges audit delivery candidates. Launch events distinguish actual delivery, an omission because the context budget is full, and a launch-time dedup that drops hits whose text is already in the ContextStore blocks/brief/task the child receives in the same message (`dedup_skipped` in the event audit). Unavailable retrieval adds an explicit warning, not an invented hit. Existing explicit handoff takes priority. Audit candidates are not a promise that the agent used them correctly.

Install dependencies: python3 -m pip install fastembed neo4j numpy. First start downloads the quantized ONNX model (~120 MB); cache is ~/.cache/mini-tui-embeddings. Install deploy/mini-tui-graph-rag.service and enable it. Projection and embeddings refresh asynchronously (3s / 5s). Warmup and failure are shown in the drawer.

UI uses native generated shadcn-svelte Tabs, upstream Control UI Timeline and upstream Beautiful UI TaskRows as real React islands, with registry receipts in vendor/. Demo timers removed; all status comes from saved task data. Drawer rail supports pointer drag and Left/Right/Home/End; width persisted locally, mobile clamped to viewport. Kanban supports horizontal scroll and hides empty columns when tasks exist.

Manual QA only, no test suites or Playwright. QA evidence: main session s-mvfu6x0q9a5b, graph retrieval at worker and leaf launch, six-byte RAG-OK file, 390px no overflow/16px fields, sidebar expanded to1146 and1342px on1366px viewport.
